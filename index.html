Day 04 — ES6+ Utility Library

All functions tested and rendered to the DOM

sum()

Takes an array of numbers, returns the total.

totalPrice()

Takes an array of items with a price property, returns total cost.

groupBy()

Groups an array of objects by a given key.

toTitleCase()

Converts a string to Title Case.

unique()

Removes duplicate values from an array.

pick()

Returns a new object with only the specified keys.

progressPercent()

Returns a percentage string from a value and max.

getNestedValue()

Safely gets a nested value using a dot-string path.
